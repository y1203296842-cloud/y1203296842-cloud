# 杨枝甘霖 · 开源项目一览

抖音同名账号「杨枝甘霖」。做内容出身，顺手把平时用的工具开源出来：全部本地运行、免费、不收集数据。

## 项目

### 1. douyin-distill — 抖音爆款拆解与博主蒸馏工具

输入对标博主的视频数据（标题、点赞/收藏/评论、口播逐字稿、封面首帧），输出一张「对标卡」：赛道与选题分布、8 类标题模式、钩子与节奏、爆款证据榜、8 维封面视觉公式。回答一个问题：他为什么火，我该怎么照着拍。

- 语言：Python（仅标准库）｜协议：MIT｜纯离线、零 API
- 仓库：https://github.com/y1203296842-cloud/douyin-distill

### 2. ai-resume2.0 — 免费开源的 AI 简历生成工具

对话式挖经历、按目标岗位的知识库重写、多模板一键导出 PDF。无后端数据库，简历内容和 API Key 只存本机浏览器，支持完全自部署。

- 技术栈：Next.js 16 + TypeScript + Tailwind CSS v4｜协议：MIT
- 仓库：https://github.com/y1203296842-cloud/ai-resume2.0

### 3. mouthpieceskill — 私人嘴替 Skill

装进 AI 助手就能用的表达辅助技能：先辨析对方潜台词，再按你本人的语气代写回怼、拒绝、安慰、祝福与高情商回复。安装即继承内置案例，个人偏好按用户隔离保存在本地。

- 语言：Python（零第三方依赖）｜协议：Apache-2.0｜主要宿主：豆包工作版
- 仓库：https://github.com/y1203296842-cloud/mouthpieceskill

## 共同原则

- **本地运行**：你的数据不出你的电脑，不经过我的服务器
- **免费开源**：可商用、可修改，保留署名即可
- **不编造**：取不到的数据写「未获取」，不拿模型凑答案
